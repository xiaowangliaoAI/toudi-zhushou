# 素材库搭建法 & 招呼语构造法

> ⚠️ **个人数据不随 skill 分发**。这份文件只讲**方法**；每个人自己的简历拆解结果（真实姓名、电话、经历细节）应当落在**自己的 workspace** 里，不进 skill 包。

## 一、先建「弹药库」，再谈打招呼

不要对着 JD 现编招呼语——**现编必翻车**（要么漏掉亮点，要么编出简历里没有的东西）。正确顺序：

```
简历 PDF → 拆成 6–8 段经历 → 每段提炼「可量化成绩」+「弹药标签」 → 得到素材库
```

### 拆解模板（每段经历填这四项）

| 项 | 要求 | 反例 |
|---|---|---|
| 起止时间 | 精确到月 | 「几年前」 |
| 公司/角色 | 用工性质写清（正式/外包/驻场/自由顾问） | 把自由顾问包装成公司实体 |
| 做了什么 | 动宾短语，**用简历原话** | 自行美化措辞 |
| 拿到了什么 | **数字优先**：人数/比率/排名/周期 | 「获得领导好评」 |

### 弹药标签的用法

每段经历提炼 4–7 个标签，标签是**检索用的索引**，不是给人看的宣传语。例：

```
〔某段经历〕 → 标签：〔场景〕 / 〔量级+数字〕 / 〔名次或结果〕 / 〔带教〕 / 〔制度或流程〕 / 〔风险结果〕
```
（上面的括号是占位符，替换成自己简历里的真实标签；**这里的标签只是索引，不是宣传语**）

后面 JD 一提到对应关键词，就直接调这个标签对应的**原话**。

### 简历别浪费的三处

1. **技能栏**（工具/系统/证书）——常被忽略，但它是「工具提效」类 JD 的直接弹药。
2. **带教/培训经历**——很多 JD 会写「新人培养」，这段经常被本人漏掉。
3. **数字**——全部原样保留，一个都不许四舍五入。

## 二、JD 强调点 → 弹药映射表（做成自己的对照表）

| 候选人沟通 / 面试邀约 | 〔…〕 | 〔…〕 |
| 批量 / 高频交付 | 〔…〕 | 〔…〕 |
| 招聘数据分析 / 招聘运营 | 〔…〕 | 〔…〕 |
| 技术岗招聘 | 〔…〕 | 〔…〕 |
| 猎聘 / 人才寻访 | 〔…〕 | 〔…〕 |

| 员工关系 / 稳定性 | 〔…〕 | 〔…〕 |
| 培训 / 带教 / 新人培养 | 〔…〕 | 〔…〕 |

> 表格里只允许填**能在简历里翻到原文**的内容。填不出来的格子空着，**空着比编着强**。

## 三、招呼语构造法（60–120 字）

### 结构（三段式）

```
① 岗位要什么（1 句，接住 JD 关键词）
② 我做过什么（1–2 句，带具体数字或场景）
③ 收口（1 句，不卑不亢）
```

### 硬规则

**要做的：**
- 只写简历里**真实存在**的事实；数字用原文，不许约等于
- 一段话说完，不用敬语堆砌
- 收口统一落在「如果还在招，可以看下我的简历」这类**不卑不亢**的收尾
- 中档匹配时，**只打做过的那部分**，不主动提没做过的

**不做的：**
- ❌ 不写「精通 / 资深 / 多年深耕」这类**无法证实的形容词**
- ❌ 不写「我很希望有机会」「麻烦您了」这类**求人语气**
- ❌ 不写「虽然我没有 X，但是…」——**自曝短板**
- ❌ 不编造：没带过的团队、没做过的项目、没有的证书，一个字都不许加
- ❌ 不把「自由顾问期」包装成公司任职

### ⚠️ 平台现实约束（实测）

**移动端/网页端的默认招呼语可能改不了。** 实测中遇到的形态是：点「立即沟通」后弹出的是**平台预设的默认招呼语**，网页端没有修改入口；定制化招呼语只能在 **App 端**或**开通相应权限后才能发**。

因此实操上分两种情况：

| 情况 | 做法 |
|---|---|
| 只能发系统默认招呼语 | **照发**（先用默认招呼语建立联系、占住沟通位），然后把**定制版文案记在清单里**，等对方回复后或换端再补 |
| 能发自定义招呼语 | 直接按上面的三段式发 |

> **别因为「发不了定制版」就不投。** 默认招呼语的作用是**建立会话**，真正的说服发生在对方回复之后。

## 四、招呼语自检清单（发出前逐条打勾）

- [ ] 每个数字都能在简历里找到原文
- [ ] 没有「精通/资深/深耕」这类形容词
- [ ] 没有「虽然我没做过…」
- [ ] 没有求人语气
- [ ] 60–120 字之间
- [ ] 接住了 JD 里的**至少一个**核心关键词
- [ ] 念一遍，像人说的话，不像模板

## 五、收尾清单必须包含的字段

每轮结束产出两份清单：

**已发清单**

| 时间 | 公司 | 招聘者 | 岗位 | 薪资 | 匹配要点 |
|---|---|---|---|---|---|

**未发清单**

| 公司 | 岗位/薪资 | 未发原因（用 `matching-rubric.md` 的代码） |
|---|---|---|

> **计数口径**：只认平台侧记录（见 `SKILL.md` 的「计数纪律」），自己的操作流水不算数。
